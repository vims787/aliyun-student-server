## 300元代金券怎么领：学生认证流程

先准备两样东西：一个完成个人实名认证的阿里云账号，和一个实名信息一致的支付宝。认证走支付宝扫码，多数情况用不到学信网材料。

1. 注册阿里云账号，完成个人实名认证。
2. 打开学生权益页，点“立即申请”，按提示先完成个人认证。
3. 刷新页面再点“立即申请”，这次会弹出学生认证二维码，用支付宝扫码。
4. 在支付宝里点“进行学生验证”。个别账号会被要求提供学信网的在线验证码（去学信网申请“教育部学籍在线验证报告”，把验证码填进支付宝认证框，一般几分钟过审），或者上传录取通知书走人工审核，按页面提示走即可。

6. 认证通过后回到权益页再点“立即申请”，填一份调查问卷并提交。
7. 点“领取”，券到账。可以在控制台的“费用与成本 → 账户 → 卡券”里确认。
